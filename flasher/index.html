Brew Controller

Put the firmware on a new controller (LILYGO T-Display S3 AMOLED Plus) straight from this page.

Before you start

  1. Use Chrome or Edge on a computer (Windows, Mac, Linux or a Chromebook). Phones, Safari and Firefox cannot talk to USB devices.
  2. Plug the board into the computer with a USB-C cable that carries data (some charging cables do not).
This browser cannot flash boards. Open this page in Chrome or Edge on a computer.
Flashing needs a secure page. Open hallge.github.io/Brew-Controller.

Click Install, pick the board in the list (it may be called USB JTAG/serial debug unit), and leave it plugged in until it says it is done. A new board should be erased when asked.

If the board is not in the list

  1. Unplug it.
  2. Hold the BOOT button on the board, plug it back in, then let go.
  3. Click Install again. After flashing, press the reset button or unplug and replug it once.

After flashing

  1. The screen shows the controller's own Wi-Fi network, BrewByWeight-xxxx. Join it from your phone or computer.
  2. Open http://192.168.4.1 in a browser.
  3. Enter your home Wi-Fi there. Later updates come over Wi-Fi (Setup, Firmware), so you only need this page once.

No Chrome or Edge? Each release also has BrewController-Flasher.exe for Windows. It is not code-signed, so Windows SmartScreen says "Windows protected your PC": click More info, then Run anyway. Source and instructions: github.com/hallge/Brew-Controller.
